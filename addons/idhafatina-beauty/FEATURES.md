# إضافات بليسك — الـ12 إضافة لمتاجر التجميل والعناية

المعرّفات نفسها (`stylist` … `presets`) حتى تبقى إعدادات `oc_addon_<id>` في twilight.json شغّالة.
البيانات في `beauty-data.json`؛ بعد تعديلها شغّل: `node addons/idhafatina-beauty/build-data.js`.

| المعرّف | الاسم | وظيفته | يعتمد على |
|---|---|---|---|
| stylist | مستشارة الجمال | بحث حر في منتجات المتجر + أجوبة الشحن والاسترجاع والدفع من صفحات المتجر | بحث سلة |
| voice | البحث الصوتي | بحث بالصوت (ar-SA / en-US) | Web Speech |
| listen | اسمعي طريقة الاستخدام | قراءة الوصف وطريقة الاستخدام | speechSynthesis |
| tryon | حجم العبوة الحقيقي | مستطيل بحجم العبوة الفعلي (ملم) | `mm` |
| recolour | اختاري الدرجة | درجات البشرة/الشفاه/الشعر/الأظافر ثم المنتجات المطابقة | `finish` |
| photocoach | نصائح الاستخدام والحفظ | اختبار الحساسية، الحفظ، الصلاحية بعد الفتح | `photo` |
| colorbook | دليل الدرجات | كل الدرجات المتوفرة بأنواع المتجر | `finish` |
| look | أكملي الروتين | منتجات تكمّل الروتين | `kit` |
| quiz | اختبار بشرتك واحتياجك | سؤالان لكل نوع ثم بحث بالنتيجة | `quiz` |
| undertone | يناسب بشرتك؟ | جافة / دهنية / مختلطة / حساسة… | `compat` |
| giftfinder | مكتشف الهدايا | حسب الميزانية بعملة المتجر | `gift` |
| presets | روتينات جاهزة | روتين أو باقة حسب نوع المتجر | `bundle` |

أدوات إضافية في `src/assets/js/obsidian/beauty.js`: مدقق المكوّنات، وتقدير «قبل ما يخلص» مع تذكير إعادة الطلب.
