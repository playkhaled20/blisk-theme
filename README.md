# بليسك · Blisk

ثيم سلة (Twilight) فاخر لمتاجر التجميل والعناية، مبني على رائد (MIT) وعلى خبرة ثيمي هانغول وبهاء.

- 11 نوعاً: التجميل والعناية (عام)، العناية بالبشرة، المكياج، العطور، الشعر، الجسم، هدايا ومجموعات، أجهزة التجميل، الأظافر، الجمال الكوري، العناية الرجالية.
- يقرأ المتجر تلقائياً (تصنيفات ومنتجات وتقييمات) ويختار النوع، مع إمكانية تحديده من الإعدادات.
- أدوات ذكية من بيانات المتجر فقط: مدقق المكوّنات، تقدير «قبل ما يخلص» وتذكير إعادة الطلب، 12 إضافة (مستشارة الجمال، الدرجات، الروتين…).
- الدليل الكامل وأدوات الاختبار: `docs/playbook/`.
